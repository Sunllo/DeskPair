Кроссплатформенная (Windows / macOS / Linux) система удалённого рабочего стола, написанная на C# / .NET 10.

- **Настольное приложение** (Avalonia) — управляющая и управляемая стороны в одном приложении.
- **Мобильные приложения** (Kotlin Multiplatform, Android и iOS) — управляющая сторона на телефоне.
- **Rendezvous** — реестр ID, статус «в сети» и сигнализация для прохода через NAT (hole punching).
- **Relay** — ретрансляция TCP для устройств, которые не могут соединиться напрямую.

Учётные записи необязательны: они связывают компьютер или телефон с человеком и держат список сохранённых компьютеров
одинаковым на всех его устройствах. Это сервис на `deskpair.app`, к которому приложения обращаются по HTTPS
(`/api/v1`); его код не публикуется.

Архитектура заимствует идеи у [RustDesk](https://github.com/rustdesk/rustdesk), но использует собственный протокол
(сообщения protobuf, сквозное шифрование AES-256-GCM, идентификация по ECDSA P-256). См. `docs/architecture.md`;
документы в `docs/` написаны на традиционном китайском.

## Загрузка

Каждый выпуск есть на [странице выпусков](https://github.com/Sunllo/DeskPair/releases/latest) и на
[deskpair.app/download](https://deskpair.app/download), с SHA-256 для каждого файла (`SHA256SUMS`).

| Система | Файлы |
|---|---|
| Windows 10 1809 или новее | x64, ARM64 и x86 (32 бита): для каждой — установщик (`.msi`) и портативный `.zip`, с именами вида `DeskPair-<version>-win-x64.msi`. С подписью кода; пока новый выпуск не наберёт репутацию, SmartScreen может всё же спросить подтверждение перед первым запуском. |
| macOS 13 или новее | `DeskPair-<version>-arm64.dmg` (Apple Silicon), `-x86_64.dmg` (Intel). Подписаны и заверены Apple (нотаризация). |
| Linux, glibc 2.31 или новее | x64, ARM64 и 32-битный ARM (ARMv7): для каждой — `.deb`, `.rpm`, пакет Arch и `.tar.gz`. |

В Windows установщик помещает DeskPair в Program Files, добавляет его в меню «Пуск» и в «Параметры › Приложения»,
откуда его можно и удалить; следующие версии приложение устанавливает само, как только администратор даст
согласие. Архив `.zip` работает там, куда его распаковали, и обновляется сам. Чтобы установить без вопросов,
например сразу на много компьютеров:

```
msiexec /i DeskPair-<version>-win-x64.msi /qn
```

В Linux установите пакет для своего дистрибутива его штатными средствами (показаны имена для x64):

```
sudo apt install ./deskpair_<version>_amd64.deb                              # Debian, Ubuntu, Mint, Raspberry Pi OS
sudo dnf install ./deskpair-<version>-1.x86_64.rpm                            # Fedora, RHEL
sudo zypper install --allow-unsigned-rpm ./deskpair-<version>-1.x86_64.rpm    # openSUSE
sudo pacman -U deskpair-<version>-1-x86_64.pkg.tar.zst                        # Arch, Manjaro
```

Пакет устанавливает DeskPair в `/usr/lib/deskpair`, делает команду `deskpair` доступной в пути и добавляет пункт в
меню приложений. Когда выходит новая версия, приложение сообщает об этом, и вы устанавливаете новый пакет тем же
способом. Архив `.tar.gz` работает в любом дистрибутиве там, куда его распаковали, и обновляется сам, как версии для
Windows и macOS.

Мобильные приложения, управляющие компьютером, пока не опубликованы в магазинах.

## Сборка

```
dotnet build DeskPair.slnx
dotnet test DeskPair.slnx
```

Нужен .NET 10 SDK (`global.json`). Видео кодирует кодировщик операционной системы (в Windows — Media Foundation).
Программный кодек H.264 в этом репозитории не поставляется — патенты на H.264 не зависят от исходного кода OpenH264
под лицензией BSD-2, — но его можно подключить самостоятельно; см. `native/openh264/README.md`.

## Управляемый компьютер и настольное приложение

DeskPair — один исполняемый файл. При запуске он показывает ваш ID и одноразовый пароль, позволяет подключаться к
другим компьютерам и в том же процессе запускает движок управляемой стороны: открытое приложение делает этот
компьютер доступным для управления, закрытое — прекращает это.

```
# приложение
dotnet run --project src/DeskPair.Desktop

# только движок, без окна: для машины без сеанса рабочего стола
dotnet run --project src/DeskPair.Desktop -- --server
```

**Автономный доступ** — возможность подключиться, когда компьютер заблокирован или никто не вошёл в систему, — это
роль, которую устанавливают в разделе Настройки › Безопасность › Доступен, когда заблокирован: служба в Windows,
агент launchd в macOS и демон root в Linux. См. `docs/unattended-windows.md` и `docs/unattended-linux.md`. Без неё
включите Настройки › Общие › **Запускать при входе в систему**, чтобы компьютер был доступен после перезагрузки и
входа в систему.

В macOS запускайте приложение из пакета `.app`: разрешения на запись экрана и универсальный доступ выдаются пакету,
а программа, запущенная из терминала, получает разрешения терминала. Поэтому там `--server` годится только для
тестов.

Чтобы использовать свои серверы, укажите сервер rendezvous и его открытый ключ в настройках (или в `config.json`);
прямые подключения к `host:21118` не требуют никакого сервера.

## Быстрый старт (командная строка без окна)

```
# 1. серверы (по умолчанию: rendezvous udp+tcp/21116, nat-test 21115, http 21114; relay tcp/21117)
dotnet run --project src/DeskPair.Rendezvous
dotnet run --project src/DeskPair.Relay -- --Relay:HttpPort=21124

# 2. прочитать ключ сервера, которому должны доверять клиенты
curl http://127.0.0.1:21114/key

# 3. управляемая сторона (печатает свой 9-значный ID и временный пароль)
dotnet run --project tools/DeskPair.Tools.PeerCli -- host --server 127.0.0.1 --key <KEY> --password secret

# 4. управляющая сторона, в другом терминале; введённые строки отправляются как сообщения чата
dotnet run --project tools/DeskPair.Tools.PeerCli -- connect <ID> --server 127.0.0.1 --key <KEY> --password secret
```

Подключение по ID пробует сначала адрес в локальной сети (при одинаковом внешнем IP), затем проход через NAT по TCP и
лишь потом relay; `--force-relay` (PeerCli) / `ForceRelay` пропускает прямые пути. См. `docs/nat-test-matrix.md`.

Docker: `docker compose -f deploy/docker-compose.yml up --build` (сеть хоста; примечания — в самом файле).
Как запускать серверы всерьёз: `deploy/README.md`.

## Лицензия

DeskPair — свободная программа под [GNU Affero General Public License версии 3](../../LICENSE)
(`AGPL-3.0-only`), которая одинаково распространяется на приложения и серверы в этом репозитории. Что важно, если вы
держите серверы для других людей: раздел 13 требует предложить этим людям исходный код того, что у вас реально
работает, включая ваши изменения.

Сторонние компоненты сохраняют свои лицензии; приложение перечисляет их в разделе Настройки › О DeskPair.
